01 / 一个图标够了

不弹窗、不占地方，
扫一眼就知道还能撑多久。

图标是运行时用 GDI+ 现画的：鼠标轮廓 + 滚轮 + 按键缝，按电量从下往上填充。16×16 像素，认得出是鼠标，也看得出余量。

40% 以上· 一切正常
16% – 40%· 该留意了
15% 及以下· 弹一次气泡提醒
断开 / 无设备· 整只灰显，仍保留最后读数
01 / READ ONLY

只读，什么都不改

不装驱动、不碰 DPI 和灯效、不监听键鼠输入。只读设备属性，外加一个可随时取消的开机启动项。

02 / 认标准不认品牌

换鼠标不用改代码

读的是 Windows 已经从标准 BLE 电池服务采好的数据。罗技、微软、小米、AULA……只要实现了标准电池服务就行。

03 / 后台线程

界面永远不卡

单次设备查询要 1–2 秒，全部丢到后台 Runspace。主线程只做 1 秒一跳的调度，托盘菜单点了就开。

02 / 原理

不逆向协议，只读系统已经采好的数

很多厂商把电量藏在自己的软件窗口里，关掉软件就看不见 —— 那意味着每家都要抓包逆向一遍。MousePowerTray 走的是标准链路。

04 / 边界

说清楚它做不到什么

一个诚实的工具应该先划边界。下面这些不是"待实现"，是物理上做不到。

  • ✓标准 BLE 电池服务的输入设备
  • ✓鼠标 / 键盘 / 部分手柄，多台可切换
  • ✓断开重连，自动识别
  • ✗2.4G 接收器，厂商私有协议，一家一套
  • ✗纯经典蓝牙耳机，电量不落进系统
  • ✗手环，私有服务 + 需要 auth key
