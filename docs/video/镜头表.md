## 视听设计说明

**色彩**：只用一个信号色 `#19FAC6`，其余靠黑 `#070907` 与墨绿灰 `#1B241B` 建立层次。S2 的电量条在变灰前保持同色系，避免出现第二个色相抢注意力。

**排印**：Cascadia Mono / Consolas。全部左对齐，行距 1.6。数字（44、12.9）永远用同一个字号体系，不因强调而跳级。

**节奏**：前 3 秒是纯黑加打字，属于"故意慢"——制造终端正在启动的临场感；7.6s 图标弹入是全片唯一的重音；18.4s 之后完全静止，不拖尾。

**禁止项**：无粒子、无光晕、无渐变扫光、无匀速平移动画、无音效（本片无声，靠打字与计数承担节奏）。

## 录制接口

```bash
# 1. 无头浏览器逐帧录制（Playwright + 本机 Edge）
node record.js            # 输出 promo/motion.webm

# 2. 转码成 H.264 MP4
node_modules/ffmpeg-static/ffmpeg.exe -i promo/motion.webm \
  -c:v libx264 -pix_fmt yuv420p -crf 20 -movflags +faststart \
  docs/video/MousePowerTray-promo.mp4
```

页面带 `?record=1` 时隐藏播放控件、自动起播，播完置 `window.__DONE = true`，录制脚本据此判断收尾时机。
